# 安全信息与事件管理系统企业能力

## 领域覆盖

- **日志数据源**：接入终端、网络、云、应用和身份日志
- **日志管道**：解析、标准化、富化、脱敏和存储
- **检测规则**：管理关联、阈值、行为和威胁规则
- **安全告警**：聚合、去重、分级和分派告警
- **安全事件**：记录范围、影响、证据和响应状态
- **调查分析**：构建时间线、实体关系和攻击路径
- **响应编排**：执行隔离、封禁、重置和通知流程
- **威胁情报**：管理IOC、信誉和命中记录
- **合规报告**：输出控制证据、留存和审计报表

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对安全信息与事件管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `SOC`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
